# Dia 16 — Scope management

```
🎯 Kambo tem scope management integrado

Antes de qualquer ação, o Kambo verifica:

✅ O alvo está dentro do escopo declarado?
✅ O subdomínio encontrado está autorizado?
✅ O IP resolvido pertence ao programa?

Nunca sair do escopo = nunca ter report rejeitado por motivo errado.

Regras de escopo são carregadas automaticamente do programa (HackerOne, Bugcrowd, Intigriti).

Hunt ético. Hunt lucrativo. 💰

🔗 github.com/ktfth/kambo
```
